# Layered architecture with interfaces

`src/app/` holds everything specific to Next.js: pages, layouts and server actions. `src/components/` holds the React UI. `src/features/` has one folder per feature with its model, repository and service, and every repository and service sits behind an interface. `src/shared/` holds the exception classes, the database and `dependency-container.ts`, the one place that creates implementations and wires them to their interfaces. Only repository implementations and the Prisma client module import Prisma. Most Next.js apps let server actions call the database directly, which needs fewer files. We chose layers and interfaces so every service can be unit-tested with fakes, and so the group's retriever can replace the stub with a one-line change in the dependency container.
